Space
Explicit geometry, viewpoint, material, and light

A repeatable prompt order

Start with the part that defines the image, then move from the large composition to visible surface detail. The order below is short enough to edit without losing track of the variable you changed.

[space type] + [dominant geometry] + [camera position and lens character] + [three key materials] + [time and light direction] + [occupancy constraint]

Use it in three moves

01

Anchor the camera

Say where the camera stands and whether the view is frontal, corner-to-corner, low, or elevated.

02

Limit the material list

Name the few surfaces that define the scene so finishes do not compete for attention.

03

Describe daylight in space

State the opening, direction, softness, and shadow length. Add people only when scale needs them.
