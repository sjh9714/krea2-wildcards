# Changelog

## 1.2.0  2026-08-22

- Added native and Dynamic Prompts ComfyUI workflows derived from the official Krea 2 Turbo template
- Added drag-and-drop PNG workflow examples with embedded, verified graph metadata
- Added focused guides for ComfyUI, product, fashion, interior, prompt writing, and image editing
- Added 12 reusable image editing recipes grounded in the repository's generated edit examples
- Added sitemap, robots directives, Dataset and CollectionPage structured data, and a 1200 by 630 social card
- Split release downloads into wildcard and workflow assets so each conversion can be counted on GitHub
- Added duplicate, length, control-character, and pending-marker prompt checks to CI

## 1.1.0  2026-08-22

- Expanded the catalog to 499 prompts across 63 categories
- Added product, packaging, fashion, interior, and architecture examples generated through Krea web
- Added prompt favorites, saved-list import and export, selection comparison, and prompt-file download tools
- Added seven translated READMEs and direct browsing links for the full visual catalog

## 1.0.0  2026-08-22

- Published 475 prompts and their unedited outputs
- Published 65 documented failures with seeds and reasons
- Reconciled all 561 generations, including 21 discarded without a surviving record
- Declared the `prompts.json` schema as version `1.0.0`
